# AutoDesign

一个无构建依赖的本地 Web 工作台：在浏览器中调用本机 ComfyUI API，无人值守生成漫剧或 MV 的图片素材。每幕图片数量不固定；每张图片可单独配置工作流、生图类型和必要节点参数。

## 启动

```powershell
cd autodesign
npm start
```

打开 `http://127.0.0.1:5173`。

AutoDesign 默认通过本地服务代理访问 `http://127.0.0.1:8188`，不需要为 ComfyUI 单独开启 CORS。
如果 ComfyUI 运行在其他地址，启动 AutoDesign 前设置 `COMFY_TARGET`。

应用直接使用导入的 ComfyUI API 工作流，不让用户重复选择 checkpoint、采样器或调度器；这些配置保留在工作流内部。`workflows/` 目录中的 ComfyUI API JSON 会自动出现在主工作流和再生工作流下拉框；没有本地目录数据时保留 `K2 漫转真 V3` 作为兜底模板。

## 使用流程

1. 在 ComfyUI 面板填写 API 地址并连接。
2. 在“项目管理”新建项目；可粘贴“内容 | 秒数”幕表并同步幕名 / 时长，供后续无人值守视频流程复用。
3. 在“幕表”下拉框中切换到某一幕，添加或编辑图片生成卡片。
4. 需要调整幕总量时，使用“调整幕数量”后同步。
5. 在每张素材卡中选择生图类型和 API 工作流。
6. 素材图导入后会自动识别并写入 `LoadImage` 节点编号；也可以手动覆盖。
7. 工作流默认参数不在工作台显示。只有手动输入节点编号并点击“映射节点参数”后，才显示该节点的可编辑基础参数；例如输入 `349` 会显示上采样方法、目标像素和分辨率档位。
8. 每幕可随时添加或删除图片生成卡片；素材工作台和生产队列管理通过页签切换。
9. 点击“加入待生产队列”后，当前序号进入队列；队列按项目、幕、序号严格排序，可在“生产队列管理”页查看或移除。
10. 点击“无人值守生成当前幕”或“无人值守生成整个项目”，应用会先检查图生图素材图，再按顺序执行并轮询结果。可随时停止队列；停止动作在当前图片完成后生效。
11. 每个生图结果下方可指定再生成序号、标题和工作流；点击后会自动把该结果图上传为 LoadImage 素材并创建图生图队列任务。所选工作流必须包含 `LoadImage` 节点。

生成结果保存在 ComfyUI 的 `output/autodesign/<项目>/第NN幕_<幕标题>/seq_NNN_<卡片ID>/` 目录中；队列顺序始终是第一幕全部序号完成后，再进入第二幕。

## 项目结构

- `index.html`：应用界面。
- `js/comfy.js`：ComfyUI API、上传、队列与工作流构造。
- `workflows/`：可直接入队并在下拉框选择的 ComfyUI API 工作流。
- `js/app.js`：界面状态、规格编辑与批量队列。
- `server.mjs`：轻量静态服务器和 `/comfy` API 代理。
